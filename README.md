# Windows Security Log Analyzer

## About
A beginner-level Python cybersecurity project
that analyzes sample login logs.

## Features
- Counts total log entries
- Counts failed login attempts
- Groups failed attempts by username
- Warns when a user has 3 or more failed attempts

## Technology
- Python
- Counter module

## How to Run
Open Command Prompt in the project folder and run:

py log_analyzer.py

## Disclaimer
This version uses sample log data.
It does not analyze real Windows Event Logs.
